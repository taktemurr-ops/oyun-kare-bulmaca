# Kare Bulmaca · Arrow Puzzle

İpucu kutularındaki okları izle!

İpuçları ızgaranın içindedir: kutudaki ok yanıtın sağa (→) mı aşağı (↓) mı yazılacağını gösterir. Bir hücreye ya da ipucu kutusuna dokun, yanıtı yaz. Bütün kareler dolunca biter.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Kelime Oyunları merkez uygulamasının oyunu; ortak motor: [kelime-motoru](https://github.com/taktemurr-ops/kelime-motoru).
